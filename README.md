# 📊 Netflix Data Analyst Dashboard

## 📌 Project Overview

This project is an interactive Netflix Data Analyst Dashboard created to analyze and visualize Netflix content data.

The dashboard provides insights into movies and TV shows available on Netflix and helps identify trends across genres, countries, ratings, languages, and release years.

## 🎯 Project Objectives

- Analyze Netflix movies and TV shows
- Compare Movies vs TV Shows
- Analyze content by genre
- Explore Netflix content by country
- Analyze content ratings
- Identify release-year trends
- Analyze languages and categories
- Generate meaningful business insights

## 🛠️ Tools & Technologies

- Tableau
- Data Visualization
- Data Cleaning
- Data Analysis
- CSV Dataset
